# 运营商余额规则证据说明

记录日期：2026-08-12

## CTExcel UK（234/33）

内置规则使用 SMS，将 `BAL` 发送到 `888`，回复发送者允许 `888` 或 `CTExcel`。该规则的证据等级为 `project_observation`，资费状态为 `unknown`。

历史项目记录（2026-08-11）曾在独立验收窗口观察到以下事实：

- 一次受控的 `BAL` 请求获得 SIP 202 和出站 RP-ACK。
- 运营商 `888` 的回复经 VoWiFi 入站链路持久化。
- 同一验收窗口未出现 QMI 短信指示或蜂窝来源通知。

这些历史事实只说明该卡和当时环境中观察到该指令可用，不构成当前命令中心余额功能的重新实发结果，也不能证明该指令免费。历史记录还未持久化入站 RP-ACK 的写入结果，因此不能据此宣称完整的双向线级确认。

## 本轮边界

本轮开发和部署只执行无副作用的服务、鉴权 API、命令目录、`/help`、SSE 和设备就绪检查。没有发送 CTExcel `BAL`、giffgaff `INFO`、USSD/USSI，也没有拨号。
